### Свои приложения для маркетплейса «Битрикс24»
Август 2026

После сокращения попробовал запуститься на той же площадке как самостоятельный разработчик. До продаж проект не дошёл и сейчас на паузе, но первое приложение и инфраструктуру под него я сделал.

- **MCP-сервер для «Битрикс24»**, первое приложение, с которого я планировал выйти на рынок. Через него ChatGPT, Claude и другие AI-агенты работают с порталом: 54 инструмента для CRM, задач, бизнес-процессов и пользователей. Каждый пользователь портала подключается со своим OAuth-токеном и своими правами, каждый запрос получает отдельный stateless-сервер с контекстом пользователя. Удаление требует явного подтверждения от агента, массовые действия идут пакетами. Внутри портала есть интерфейс с инструкциями по подключению ChatGPT и Claude. Инструменты проверяются сценариями, которые AI-агент проходит на тестовом портале.
- **Серверы.** Dokploy на dev-сервере собирает приложения и деплоит их на prod. Вход по SSH только по ключу, ufw, fail2ban, ограничения логов journald, логи контейнеров отправляются в S3 через Vector. Каждый шаг настройки описан в репозитории.
- **Сервис установки.** Одна точка входа для установки нескольких приложений через OAuth. Админ-токены порталов хранит и обновляет только этот сервис, а приложения получают их по запросу и сами токены не хранят.
- **Анализ рынка.** Парсер страниц маркетплейса в PostgreSQL, представления и функции для роста установок приложений и партнёров и поиска новых растущих приложений.
- **Поддержка пользователей.** Публичный трекер обращений на GitHub Issues с шаблонами и общей доской задач.

**Стек:** TypeScript, Node.js, MCP SDK, zod, Knex, PostgreSQL, Vue 3, Docker, Dokploy, Vector
