## Задача

У форума игры нет API, а AI-ассистенты (Claude, Cursor и другие) не умеют читать его сами. Хотелось спрашивать у ассистента «что нового на форуме» или «перескажи тему» и получать ответ по актуальным данным.

## Решение

MCP-сервер с семью инструментами: разделы, свежие темы, темы раздела, посты темы, отдельный пост, поиск игроков и их темы. Ставится одной командой через `npx`, около 600 скачиваний из npm в месяц.

- **Парсинг HTML форума** через cheerio в типизированные объекты, параметры инструментов проверяются схемами zod.
- **Защита форума и себя.** Ограничение частоты запросов, повторы с задержкой и circuit breaker: если форум лежит, запросы сразу получают понятную ошибку со временем до следующей попытки, а не ждут таймауты.
- **Вход под аккаунтом** с хранением cookie-сессии, чтобы в дальнейшем добавить действия от имени пользователя.
- **Два транспорта:** stdio для локальных клиентов и HTTP для запуска на сервере, есть Docker-образ.

## Качество

61 тест на Vitest, парсеры проверяются на сохранённых страницах настоящего форума, а отдельный скрипт обновляет эти образцы. CI запускает проверки на каждый push и PR. Публикация в npm идёт по тегу через trusted publishing (OIDC), без хранения токена в секретах.
