**Стек:** Next.js 15, TypeScript, MDX, Tailwind, shadcn/ui

**Ссылки:** [исходный код](https://github.com/exi66/website)

## Задача

Нужно было одно место для резюме, проектов и блога на двух языках, где контент легко добавлять без правки кода.

## Решение

Сайт сделан на основе шаблона документации [aria-docs](https://github.com/nisabmohd/Aria-Docs): из него взяты MDX-страницы, навигация, поиск, оглавление и двуязычность. Сверху своё:

- **Главная страница** и **форма обратной связи** с отправкой в Discord через server action.
- **Защита формы.** Валидация на сервере, ограничение частоты запросов по IP, поле-ловушка для ботов, запрет упоминаний `@everyone` в сообщении.

## Качество

CI на каждый push: аудит зависимостей, линтер, проверка типов и сборка.
