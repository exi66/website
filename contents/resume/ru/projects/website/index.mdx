## О проекте

Мой сайт-портфолио — **прямо сейчас вы находитесь на нём**. Простой сайт из нескольких страниц: главная, портфолио, блог и контактная форма. Написан на **Next.js** на основе шаблона [aria-docs](https://github.com/nisabmohd/Aria-Docs).

## Функционал

Возможности базового шаблона — все они доступны, так как сайт использует ту же основу:

- **Поддержка MDX** — интерактивный контент на MDX.
- **Вложенные страницы** — организация материалов в иерархическую структуру.
- **Раздел блога** — отдельная секция для заметок.
- **Оглавление** — автоматически генерируемый список разделов страницы.
- **Пагинация** — разбиение контента на несколько страниц.
- **Подсветка синтаксиса** — читаемое отображение кода.
- **Подсветка и заголовки строк кода** — выделение отдельных строк с пояснениями.
- **Интерактивные блоки кода** — контекстное отображение с учётом языка.
- **Кастомные компоненты** — встраивание переиспользуемых компонентов в контент.
- **Светлая и тёмная темы** — переключение оформления.
- **Поиск** — встроенный быстрый поиск по контенту.
- **Переключатель кода** — переключение между языками или вариантами примеров.
- **Копирование кода** — копирование блока кода одним кликом.
- **Подсветка активного раздела в оглавлении** — при прокрутке подсвечивается текущая секция.
- **Статическая генерация** — сборка быстрого статического сайта.
- **SEO-оптимизация** — структура для оптимальной индексации.
- **Интернационализация (i18n)** — поддержка нескольких языков.

Собственная функциональность поверх шаблона:

- **Контактная форма** — обратная связь через server actions с отправкой данных в сторонние сервисы посредством вебхука.
- **Главная страница** — классический лендинг с hero-секцией, ссылками и кнопками быстрого доступа.

## Технологии

- **Next.js** — фреймворк и статическая генерация
- **TypeScript**
- **shadcn** — UI-компоненты
- **MDX** — контент страниц
- **Docker** — деплой
