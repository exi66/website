## Задача

Слизни появляются только в определённых чанках мира, и вычисляются они из сида мира. На веб-карте игры этой информации нет, а внешние сервисы не знают сиды игровых миров.

## Решение

Userscript добавляет на карту слой со слайм-чанками. Сиды основных миров встроены, свой сид можно ввести вручную. Слой следит за сдвигом и масштабом карты и рисует только видимую область.

- **Порт алгоритма из Java в JavaScript.** Алгоритм использует `java.util.Random` и переполнение 32-битных целых, поэтому в JS он повторён через `BigInt` и `Math.imul`.
- **Обновления без участия пользователя.** Сборка через esbuild, релиз по тегу в GitHub Actions, Tampermonkey обновляет скрипт сам.

## Качество

Результат сверяется с эталоном на Java, который запускает тот же код, что и сама игра. 9 тестов, CI на каждый PR.
