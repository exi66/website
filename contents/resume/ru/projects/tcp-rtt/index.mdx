## О проекте

Приложение для мониторинга задержки (**RTT**) до игрового сервера. Измеряет реальную задержку игрового трафика за счёт перехвата TCP-пакетов на сетевом интерфейсе, без отдельных пинг-запросов к серверу.

## Функционал

- **Перехват трафика** — захват TCP-пакетов на выбранном сетевом интерфейсе.
- **Расчёт RTT** — фиксация времени отправки и ожидаемых ACK, вычисление задержки в момент ответа сервера.
- **График в реальном времени** — наглядная визуализация задержки на живом графике.
- **Порог отсечения** — отбрасывает пакеты с временем ниже заданного в мс. Это отсекает из выборки пакеты, которые не покидают сетевую карту, не искажая реальную задержку.

## Технологии

- **.NET 10 / C# / Windows Forms** — интерфейс
- **SharpPcap** (Npcap) — перехват пакетов
- **PacketDotNet** — разбор IP/TCP
- **ScottPlot** — график задержки в реальном времени
