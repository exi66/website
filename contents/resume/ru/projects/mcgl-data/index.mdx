## О проекте

Система для сбора, хранения и поиска по данным игрового проекта **[Minecraft Galaxy](https://minecraft-galaxy.ru/ru/)**. Разрозненные дампы данных приводятся к единой базе **PostgreSQL**, отдаются наружу через **PostgREST** и доступны для поиска в веб-интерфейсе.

## Функционал

- **Сбор данных** — дампы данных собираются в единую базу.
- **Поиск по тексту** — поиск по содержимому тела записи.
- **Поиск по ключам** — фильтрация по полям. Для комментариев доступны ключи `id`, `user`, `author`; для постов — `id`, `usersInText`, `linksInText`.
- **Бесконечный скролл** — пагинация результатов подгрузкой по мере прокрутки.

## Технологии

- **React**
- **shadcn** — UI-компоненты
- **PostgREST** — REST API к базе данных
- **PostgreSQL** — база данных
- **TypeScript**
- **Knex** — миграции и наполнение таблиц
