## Задача

Был архив постов и комментариев форума в разных форматах: сотни тысяч записей в HTML и текстовых дампах. Искать по нему было невозможно.

## Решение

Данные приводятся к единой схеме PostgreSQL, отдаются через PostgREST, а поиск идёт в веб-интерфейсе.

- **Импорт.** Миграции и сиды на Knex разбирают дампы, очищают HTML до текста и заполняют таблицы.
- **Поиск.** Полнотекстовый поиск по-русски (`tsvector` с русской морфологией) и поиск по подстроке на триграммных индексах `pg_trgm`, оба через GIN-индексы.
- **API без своего бэкенда.** PostgREST отдаёт отдельную схему `api` с ролью, у которой есть только права на чтение, и ограничением на число строк в ответе.
- **Интерфейс.** Строка запроса с фильтрами по полям (`user:`, `author:` и другие) и бесконечная прокрутка результатов.
- **Ссылки на поиск.** Запрос и вкладка сохраняются в адресе страницы, поэтому результатом можно поделиться.

Интерфейс сделан на [шаблоне для статических проектов](https://github.com/exi66/starter): общая тема, переводы и настройки с проверкой схемой, линтер и CI берутся из него.

## Качество

Разбор поискового запроса, работа с настройками и полнота переводов покрыты 16 тестами. Линтер (oxlint), проверка форматирования, типов и тесты запускаются на каждый PR, деплой на GitHub Pages выполняется по тегу версии после зелёного CI.
