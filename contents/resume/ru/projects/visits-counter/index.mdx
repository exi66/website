**Стек:** Node.js, Express, SQLite, Knex, Docker

**Ссылки:** [исходный код](https://github.com/exi66/visits-counter)

## Задача

Нужен был счётчик посещений для страниц, где нельзя подключить скрипты аналитики, например для поста на форуме. Достаточно картинки.

## Решение

Каждый запрос `<img src=".../counter/имя">` увеличивает счётчик и возвращает SVG с числом, цвет и размер задаются параметрами.

- **Защита от накрутки с чужих сайтов.** Учитываются только запросы с разрешённых доменов (по `Referer`, включая поддомены).
- **Валидация параметров:** цвет, ширина и высота в допустимых пределах.
- **Простое хранение.** SQLite, миграции Knex применяются при старте. Docker-образ с томом для базы.
