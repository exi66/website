Почти все проекты выросли из конкретной задачи для игровых сообществ или для себя, и большинство из них я поддерживаю до сих пор. В каждом описании есть задача, решение с ключевыми техническими деталями и то, как проверяется качество: тесты, CI, релизы.

## Крупные

- **[Платформа для модов](/resume/projects/modding-platform)**: деобфускация Java-клиента, загрузчик модов на Mixin, тесты байткода в CI. Java, Maven.
- **[mcgl-mcp](/resume/projects/mcgl-mcp)**: MCP-сервер для AI-ассистентов, около 600 скачиваний в месяц из npm. TypeScript.
- **[tcp-rtt](/resume/projects/tcp-rtt)**: замер реальной задержки до сервера по перехваченному TCP-трафику. C#, .NET.
- **[shiel-bot](/resume/projects/shiel-bot)**: Discord-бот с веб-интерфейсом, монорепозиторий из четырёх пакетов. Node.js, React.
- **[bdo-sieges](/resume/projects/bdo-sieges)**: карта для планирования осад с обменом планом одной строкой. React, Leaflet.
- **[mcgl-data](/resume/projects/mcgl-data)**: полнотекстовый поиск по архиву форума. PostgreSQL, PostgREST, React.

## Небольшие

- **[mcgl-itpe-ahk](/resume/projects/mcgl-itpe-ahk)**: перенос изображений на игровые холсты с дизерингом. Node.js, AutoHotkey.
- **[mcgl-slimes](/resume/projects/mcgl-slimes)**: userscript со слоем слайм-чанков на карте, алгоритм сверяется с эталоном на Java.
- **[visits-counter](/resume/projects/visits-counter)**: счётчик посещений в виде SVG. Express, SQLite.
- **[website](/resume/projects/website)**: этот сайт. Next.js.
