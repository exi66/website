### My own apps for the Bitrix24 marketplace
August 2026

After the layoff I tried to launch on the same marketplace as an independent developer. The project didn't reach sales and is on hold now, but I built the first app and the infrastructure for it.

- **An MCP server for Bitrix24**, the first app I planned to launch with. It lets ChatGPT, Claude and other AI agents work with a portal: 54 tools for CRM, tasks, business processes and users. Each portal user connects with their own OAuth token and permissions, and every request gets its own stateless server with that user's context. Deletes require explicit confirmation from the agent, and bulk actions run in batches. A UI inside the portal explains how to connect ChatGPT and Claude. The tools are checked with scenarios that an AI agent runs on a test portal.
- **Servers.** Dokploy on a dev server builds the apps and deploys them to prod. SSH with keys only, ufw, fail2ban, journald log limits, and container logs shipped to S3 with Vector. Every setup step is documented in the repository.
- **Install service.** A single entry point for installing several apps through OAuth. Only this service stores and refreshes the portals' admin tokens; apps request them when needed and never store tokens themselves.
- **Market research.** A parser of marketplace pages into PostgreSQL, with views and functions for app and partner install growth and for finding new fast-growing apps.
- **User support.** A public issue tracker on GitHub Issues with templates and a shared task board.

**Stack:** TypeScript, Node.js, MCP SDK, zod, Knex, PostgreSQL, Vue 3, Docker, Dokploy, Vector
