**Links:** [source](https://github.com/exi66/bdo-sieges) · [demo](https://exi66.github.io/bdo-sieges/)

## Problem

Before a siege, a guild has to agree in advance where to place forts and structures and how squads should move. There was no ready tool for laying all of this out on the real map and sharing the plan with others.

## Solution

A Leaflet map with real nodes and territories from the game. You can place markers with a color, icon and label, draw shapes, measure distances and view 360° panoramas.

- **Game coordinates.** Nodes, territories and panoramas are stored in game coordinates and converted to the map's coordinate system; the ruler shows distances in in-game meters.
- **Sharing a plan as one string.** Markers are compressed with deflate (`CompressionStream`) and encoded as base64url. The new code format is much shorter than the old one, and old codes can still be imported. Markers are validated on import.
- **No backend.** State is stored in localStorage, the site is built as static files and published to GitHub Pages.
- Russian and English UI, light and dark theme.

## Quality

CI checks types and lint, and deployment to GitHub Pages is automatic.
