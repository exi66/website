## About

An interactive map for planning sieges in **Black Desert Online**. It lets you place various objects on the game map to think through a battle before it even begins.

## Features

- **Object placement** — drop elements onto the map to visualize the siege plan.
- **Territory borders** — the real battle zones, pulled straight from the game.
- **base64 export** — a finished layout can be exported as a single string and shared.
- **Localization** — the interface is available in several languages.
- **Panoramic viewer** — an experimental viewer similar to Google Street View.

## Tech stack

- **React**
- **TypeScript**
- **Leaflet** — the interactive map
- **shadcn** — UI components
