## About

A timeline of the **[Minecraft Galaxy](https://minecraft-galaxy.ru/ru/)** gaming project. Built on a fork of [TimelineJS by Knightlab](https://timeline.knightlab.com/). The data is maintained in a Google Sheet.

## Fork improvements

The custom fork of TimelineJS adds and fixes:

- **Colored eras** — the ability to color eras (time spans) individually.
- **Cyrillic event links** — fixed generation of links to events that have Cyrillic titles.
- **Bookmark on jump to start/end** — fixed updating the bookmark (URL) when navigating to the first or last event.
- **No proxy required** — a proxy server is no longer needed to run it.
