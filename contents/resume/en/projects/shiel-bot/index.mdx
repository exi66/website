**Stack:** Node.js, discord.js (Sapphire), Express, SQLite, React, TypeScript, Vite, shadcn/ui

**Links:** [source](https://github.com/exi66/shiel-bot) · [web UI](https://shiel.bdo.exi.moe/)

## Problem

Rare items on the Black Desert Online marketplace first go into a registration queue and can only be bought at the moment they are listed. To not miss an item, you had to watch the queue manually. New in-game coupons are also easy to miss.

## Solution

Every minute the bot polls the marketplace queue and the coupon list and sends a Discord direct message when an item from the user's subscriptions or a new coupon appears. Subscriptions are managed in a web UI: the `/settings` command gives a personal link with an expiry, so no separate sign-up is needed.

The project is a pnpm monorepo with four packages:

- **bot**: the Discord bot and background polling jobs
- **server**: the Express API that also serves the built frontend
- **web**: the settings UI in React
- **shared**: shared config, logger and database access

Details:

- **No repeated notifications after a restart.** The first iteration only records the current state; notifications start from the second one.
- **SQLite schema migrations** with the version stored in `PRAGMA user_version`, without external tools.
- **Type checking for the JS packages** via TypeScript's `checkJs`, without rewriting them in TS.

## Quality

Parsers, the item catalog, validation and migrations are covered by tests (`node --test`). CI runs the linter, type checking and tests.
