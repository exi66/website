This is a collection of my personal projects — mostly web apps and tools for gaming communities and for myself. Almost every one grew out of a concrete need: something was missing, so a solution appeared. I still maintain them, and from time to time updates ship that extend their functionality.

## Minecraft Galaxy

A set of web tools for the gaming project:

- **[mcgl-timeline](/resume/projects/mcgl-timeline)** — an interactive timeline of the project's history.
- **[mcgl-arts](/resume/projects/mcgl-arts)** — a web gallery of pixel art.
- **[mcgl-slimes](/resume/projects/mcgl-slimes)** — a slime-chunk layer for the web map.
- **[mcgl-data](/resume/projects/mcgl-data)** — a unified database and search over the project's data.
- **[mcgl-correct-evasion-calculator](/resume/projects/mcgl-correct-evasion-calculator)** — evasion and armor-enhancement efficiency calculator.
