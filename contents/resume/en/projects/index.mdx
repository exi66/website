Almost every project grew out of a specific need, for gaming communities or for myself, and I still maintain most of them. Each page describes the problem, the solution with its key technical details, and how quality is checked: tests, CI, releases.

## Major

- **[Modding platform](/resume/projects/modding-platform)**: deobfuscation of a Java client, a Mixin-based mod loader, bytecode tests in CI. Java, Maven.
- **[mcgl-mcp](/resume/projects/mcgl-mcp)**: an MCP server for AI assistants, about 600 downloads a month on npm. TypeScript.
- **[tcp-rtt](/resume/projects/tcp-rtt)**: real latency to a server measured from captured TCP traffic. C#, .NET.
- **[shiel-bot](/resume/projects/shiel-bot)**: a Discord bot with a web UI, a monorepo of four packages. Node.js, React.
- **[bdo-sieges](/resume/projects/bdo-sieges)**: a siege planning map that shares a plan as one string. React, Leaflet.
- **[mcgl-data](/resume/projects/mcgl-data)**: full-text search over a forum archive. PostgreSQL, PostgREST, React.

## Smaller

- **[mcgl-correct-evasion-calculator](/resume/projects/mcgl-correct-evasion-calculator)**: an evasion calculator with a graph. Vue 3.
- **[mcgl-itpe-ahk](/resume/projects/mcgl-itpe-ahk)**: transfers images onto in-game canvases with dithering. Node.js, AutoHotkey.
- **[mcgl-slimes](/resume/projects/mcgl-slimes)**: a userscript with a slime chunk layer on the map, checked against a Java reference.
- **[visits-counter](/resume/projects/visits-counter)**: a visit counter served as an SVG. Express, SQLite.
- **[website](/resume/projects/website)**: this site. Next.js.

## Other

- **[mcgl-arts](https://github.com/exi66/mcgl-arts)**: a gallery of players' pixel art. React.
