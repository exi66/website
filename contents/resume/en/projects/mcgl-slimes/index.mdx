## Problem

Slimes spawn only in certain chunks of the world, which are derived from the world seed. The game's web map doesn't show this, and external services don't know the seeds of the game's worlds.

## Solution

The userscript adds a slime chunk layer to the map. Seeds of the main worlds are built in, and you can enter your own seed. The layer follows map panning and zoom and draws only the visible area.

- **Porting the algorithm from Java to JavaScript.** The algorithm relies on `java.util.Random` and 32-bit integer overflow, so in JS it is reproduced with `BigInt` and `Math.imul`.
- **Updates without user action.** Built with esbuild, released on a tag in GitHub Actions, and Tampermonkey updates the script itself.

## Quality

Results are checked against a Java reference that runs the same code as the game. 9 tests, CI on every PR.
