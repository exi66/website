**Stack:** Next.js 16, TypeScript, MDX, Tailwind, shadcn/ui

**Links:** [source](https://github.com/exi66/website)

## Problem

I needed one place for my resume, projects and blog in two languages, where content is easy to add without touching code.

## Solution

The site is based on the [aria-docs](https://github.com/nisabmohd/Aria-Docs) documentation template, which provides MDX pages, navigation, search, table of contents and two-language support. On top of it:

- **The home page** and **a contact form** that sends messages to Discord through a server action.
- **Form protection.** Server-side validation, per-IP rate limiting, a honeypot field for bots and blocking `@everyone` mentions in messages.

## Quality

CI on every push: dependency audit, lint, formatting, type checking, tests and build. Deployed by Dokploy on a push to main.
