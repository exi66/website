## About

My portfolio site — **you are on it right now**. A simple site made of a few pages: home, portfolio, blog and a contact form. Written in **Next.js**, based on the [aria-docs](https://github.com/nisabmohd/Aria-Docs) template.

## Features

Base template capabilities — all available, since the site uses the same foundation:

- **MDX support** — interactive content written in MDX.
- **Nested pages** — content organized in a nested, hierarchical structure.
- **Blog section** — a dedicated section for notes.
- **Table of contents** — an auto-generated TOC for each page.
- **Pagination** — content split across multiple pages.
- **Syntax highlighting** — readable code rendering.
- **Code line highlighting & titles** — highlight specific lines with descriptions.
- **Interactive code blocks** — language-aware, contextual code display.
- **Custom components** — embed reusable components in the content.
- **Light & dark mode** — toggle between themes.
- **Search** — built-in quick content search.
- **Code switcher** — switch between languages or example variations.
- **Code copy** — copy a code block with a single click.
- **TOC observer highlight** — highlights the active section as you scroll.
- **Static site generation** — builds a fast static site.
- **SEO-optimized** — structured for optimal indexing.
- **Internationalization (i18n)** — support for multiple languages.

Custom functionality on top of the template:

- **Contact form** — a feedback form using server actions that sends the input to third-party services via a webhook.
- **Home page** — a classic landing page with a hero section, links and quick-access buttons.

## Tech stack

- **Next.js** — framework and static generation
- **TypeScript**
- **shadcn** — UI components
- **MDX** — page content
- **Docker** — deployment
