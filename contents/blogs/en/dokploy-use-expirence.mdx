## What Dokploy is

[Dokploy](https://dokploy.com) is a self-hosted platform for deploying and managing applications and databases, built around a "no vendor lock-in" principle: everything runs on your own server, with no tie-in to a specific cloud provider and no monthly deployment fees.

Essentially, it's an open-source alternative to services like Vercel, Netlify, or Heroku, with one important difference — it isn't a managed service, it's a tool you host yourself. Dokploy installs with a single command:

```bash
curl -sSL https://dokploy.com/install.sh | bash
```

From there, everything — apps, databases, servers — is managed through a web interface.

## The problem it solves

To publish a regular web app, a developer usually has to take on a whole set of adjacent tasks: set up the web server and its environment, build an image and configure Docker, set up CI/CD, watch logs and resource usage, and, for a database, stand it up and maintain it separately.

Dokploy takes all of that work off your hands and hides it behind a graphical interface.

## Deploying applications

Dokploy supports several ways to build and run an application:

- **Nixpacks** — automatic stack detection and build with zero configuration
- **Heroku Buildpacks** — the same approach classic Heroku uses
- **a plain Dockerfile** — for full control over the build
- **Docker Compose** — for more complex, multi-service applications

Applications in **Node.js, PHP, Python, Go, Ruby**, and other languages are all supported — the platform doesn't care what the project is written in, as long as it fits one of these build methods. Deploys trigger on a git push to a branch or on creating a tag, so once the initial setup is done, deployment becomes fully automatic.

## Everything else

Beyond deployment itself, Dokploy also covers everything that usually surrounds it:

- **databases** — create and maintain MySQL, PostgreSQL, MongoDB, MariaDB, Redis, and libSQL right from the interface, with automated backups and quick restoration
- **ready-made templates** — Supabase, Cal.com, Plausible, PocketBase, and 200+ others spin up in one click, with no manual docker-compose setup
- **monitoring and notifications** — real-time CPU, memory, disk, and network usage, detailed logs, and notifications about successful and failed deploys via Slack, Discord, Telegram, or email
- **scaling and access** — managing multiple servers and clustering via Docker Swarm, plus a role-based access model with fine-grained permissions for teams

## The bottom line

Dokploy closes exactly the gap that usually forces a developer to either dive into DevOps or pay for a managed platform. Reverse proxying, certificates, image builds, push-to-deploy, databases with backups, and monitoring are all already set up and tucked behind a straightforward interface — while the server itself stays entirely yours.
